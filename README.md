# 🌱 Learn with Eyes — Class 4 Science

Visual learning platform for Class 4 Science (Unit I: Food & Health), inspired by [Learn with Eyes](https://tanisha-406.github.io/learn-with-eyes/).

## Chapters Included
1. **Nutrients in Our Food** — Carbohydrates, Fats, Proteins, Vitamins & Minerals, Roughage, Water & Milk, plus 3 YouTube video lessons and an 8-question quiz from `Class4.pdf`.
2. **Balanced Diet** — Balanced Diet, Food Pyramid, Good Eating Habits, Food Preservation, and a 7-question quiz from `Class4.pdf`.

## Features
- Bilingual English / Hindi toggle (`🇮🇳 EN/हिं`)
- Font size scaling (`A⁺`) & Dark / High-Contrast mode (`🌙`)
- Student profile & `localStorage` quiz score tracking
- Progress Dashboard

## Run Locally
Open `index.html` in any browser, or serve with:
```bash
python3 -m http.server 8000
```
